# Create User Request


## Request


### URL


`POST api/v1/user`


### Body


```json

{

    "data": {

        "attributes": {

            "id" : "1",

            "name": "someName",

            "email": "someEmail@gmail.com",

            "phoneNumber": "89204050777",

            "createdAt" : "2025-10-02T14:30:00Z"

        }

    }

}

```

## Response


`201 Created`
